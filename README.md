# LLM Evaluation Toolkit

A practical starter toolkit for reviewing AI-generated responses consistently and documenting evidence-based quality judgments.

## Evaluation dimensions

1. Instruction compliance
2. Relevance
3. Factual support
4. Reasoning quality
5. Completeness
6. Clarity
7. Safety and uncertainty handling

## Suggested workflow

1. Read the task and identify explicit constraints.
2. Review the response without scoring.
3. Verify claims, calculations, assumptions, and terminology.
4. Score each rubric dimension.
5. Record specific evidence for strengths and weaknesses.
6. Recommend the smallest changes needed to improve the response.

## Purpose

This repository demonstrates a clear, repeatable approach to LLM evaluation, AI quality assurance, technical review, and written feedback.
